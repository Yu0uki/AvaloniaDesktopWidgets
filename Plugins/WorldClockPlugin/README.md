# 世界时钟插件 (WorldClock Plugin)

## 功能特性

### 1. 世界时钟
- ✅ 显示当前系统时间
- ✅ 支持多个时区切换（包括主要城市和国家）
- ✅ 实时更新时间（每秒刷新）
- ✅ 显示时区对应的城市和国家信息

### 2. 秒表功能
- ✅ 精确到毫秒的计时
- ✅ 开始/停止/重置控制
- ✅ 直观的显示界面

### 3. 计时器功能
- ✅ 可自定义倒计时时长
- ✅ 开始/停止/重置控制
- ✅ 倒计时结束自动停止

### 4. 设置界面
- ✅ 自定义时间格式
- ✅ 独立窗口模式选项
- ✅ 显示秒数开关
- ✅ 24小时制/12小时制切换

## 安装方法

插件已自动构建并复制到 `Plugins` 目录。启动主应用程序后，插件会自动加载。

## 使用方法

### 基本使用

1. **启动应用**：运行 AvaloniaApplication2 主程序
2. **导航到插件管理**：点击左侧导航栏的"插件管理"按钮
3. **查看插件**：世界时钟插件应该已经自动加载并显示在列表中
4. **打开插件**：点击插件卡片上的"打开"按钮

### 时区切换

1. 在世界时钟界面顶部，找到时区下拉框
2. 选择您想要查看的时区
3. 时间会自动更新为所选时区的当前时间
4. 下方会显示对应的城市和国家信息

可用时区包括：
- 本地（中国）
- UTC（协调世界时）
- 纽约（美国）
- 洛杉矶（美国）
- 伦敦（英国）
- 巴黎（法国）
- 东京（日本）
- 上海（中国）
- 香港（中国）
- 悉尼（澳大利亚）

### 使用秒表

1. 切换到"⏱️ 秒表"标签页
2. 点击"▶ 开始"按钮开始计时
3. 点击"⏸ 停止"按钮暂停计时
4. 点击"🔄 重置"按钮将秒表归零

### 使用计时器

1. 切换到"⏲️ 计时器"标签页
2. 在"设置时长"输入框中输入分钟数
3. 点击"▶ 开始"按钮开始倒计时
4. 可以随时点击"⏸ 停止"暂停
5. 点击"🔄 重置"按钮恢复初始设置

### 设置配置

1. 在插件管理器中找到世界时钟插件
2. 点击"设置"按钮（如果可用）
3. 或者在插件内部查找设置入口

可配置项：
- **时间格式**：自定义时间显示格式（如：yyyy-MM-dd HH:mm:ss）
- **独立窗口**：启用后插件将在独立窗口中显示
- **显示秒数**：控制是否显示秒
- **24小时制**：切换12/24小时制

## 技术实现

### 架构设计

插件遵循主应用的插件架构规范：
- 实现 `IPlugin` 接口
- 提供主视图和设置视图
- 支持插件生命周期管理（Initialize, Activate, Deactivate, Shutdown）

### 核心组件

1. **WorldClockPlugin.cs**：插件主类，实现 IPlugin 接口
2. **WorldClockViewModel.cs**：时钟、秒表、计时器的视图模型
3. **WorldClockView.axaml**：主界面UI
4. **SettingsViewModel.cs**：设置的视图模型
5. **SettingsView.axaml**：设置界面UI

### 定时器实现

- 时钟更新：使用 `System.Timers.Timer`，每秒更新一次
- 秒表：每10毫秒更新一次，确保精度
- 计时器：每秒更新一次倒计时

## 开发说明

### 项目结构

```
Plugins/WorldClockPlugin/
├── ViewModels/
│   ├── WorldClockViewModel.cs    # 主视图模型
│   └── SettingsViewModel.cs      # 设置视图模型
├── WorldClockPlugin.cs           # 插件主类
├── WorldClockView.axaml          # 主界面
├── WorldClockView.axaml.cs       # 主界面代码
├── SettingsView.axaml            # 设置界面
├── SettingsView.axaml.cs         # 设置界面代码
└── WorldClockPlugin.csproj       # 项目文件
```

### 构建插件

```bash
cd Plugins/WorldClockPlugin
dotnet build -c Release
```

构建后的DLL位于：`bin/Release/net10.0/WorldClockPlugin.dll`

### 调试技巧

1. 查看主应用日志文件了解插件加载状态
2. 日志位置：`AvaloniaApplication2/bin/Debug/net10.0/Logs/`
3. 检查插件是否正确实现 IPlugin 接口
4. 确保所有绑定都正确配置

## 故障排除

### 插件未加载

1. 检查DLL文件是否在 `Plugins` 目录
2. 查看日志文件中的错误信息
3. 确认插件实现了 IPlugin 接口
4. 检查依赖项是否正确

### 时间显示不正确

1. 检查系统时区设置
2. 确认选择了正确的时区
3. 检查时间格式字符串是否正确

### 秒表/计时器不工作

1. 检查是否有其他程序占用资源
2. 重启应用程序
3. 查看控制台输出是否有错误
