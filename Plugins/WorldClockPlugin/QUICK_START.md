# 世界时钟插件 - 快速开始指南

## 🚀 5分钟上手

### 第一步：启动应用
```bash
cd f:\Programs\project\AvaloniaApplication2
dotnet run --project AvaloniaApplication2
```

### 第二步：找到插件
1. 应用启动后，点击左侧导航栏的 **🔌 插件管理**
2. 在插件列表中找到 **"世界时钟"** 插件
3. 确认插件状态为"已启用"和"已加载"

### 第三步：打开插件
点击插件卡片上的 **"打开"** 按钮

### 第四步：探索功能

#### 🌍 查看世界时间
1. 默认显示本地时间
2. 使用顶部的时区下拉框切换时区
3. 观察时间和地点信息的变化

#### ⏱️ 使用秒表
1. 点击 **"⏱️ 秒表"** 标签
2. 点击 **"▶ 开始"** 开始计时
3. 点击 **"⏸ 停止"** 暂停
4. 点击 **"🔄 重置"** 归零

#### ⏲️ 使用计时器
1. 点击 **"⏲️ 计时器"** 标签
2. 输入倒计时分钟数（例如：5）
3. 点击 **"▶ 开始"** 开始倒计时
4. 可以随时停止或重置

#### ⚙️ 自定义设置
1. 查找设置按钮（如果可用）
2. 配置时间格式
3. 选择是否使用独立窗口
4. 保存设置

## 💡 常用场景

### 场景1：查看纽约时间
1. 打开世界时钟插件
2. 在时区下拉框中选择 **"America/New_York"**
3. 看到显示：**纽约 | 美国** 和对应的时间

### 场景2：会议计时
1. 切换到 **"⏲️ 计时器"** 标签
2. 输入 **30** 分钟
3. 点击 **"▶ 开始"**
4. 专注工作，计时器会自动倒计时

### 场景3：运动计时
1. 切换到 **"⏱️ 秒表"** 标签
2. 点击 **"▶ 开始"**
3. 进行运动
4. 完成后点击 **"⏸ 停止"** 查看用时

### 场景4：多时区对比
1. 先查看本地时间
2. 切换到 **UTC** 查看国际标准时间
3. 切换到 **Tokyo** 查看日本时间
4. 快速了解全球时间差异

## 🎯 快捷键提示

虽然当前版本不支持键盘快捷键，但您可以：
- 使用鼠标快速点击切换
- Tab键在不同控件间切换
- Enter键激活按钮

## 🔧 常见问题

**Q: 插件没有显示在列表中？**
A: 检查 `Plugins` 目录是否有 `WorldClockPlugin.dll` 文件

**Q: 时间不准确？**
A: 检查您的系统时间和时区设置是否正确

**Q: 如何添加更多时区？**
A: 目前支持10个主要时区，未来版本会添加更多

**Q: 设置会保存吗？**
A: 当前版本的设置在重启后会重置，未来版本会支持持久化
