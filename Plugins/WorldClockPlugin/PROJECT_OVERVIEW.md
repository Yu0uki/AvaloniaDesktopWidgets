## 🏗️ 架构设计

### 设计模式
1. **MVVM模式**: 分离视图、视图模型和模型
2. **插件模式**: 实现标准IPlugin接口
3. **观察者模式**: 使用ObservableProperty自动通知
4. **命令模式**: 使用RelayCommand处理用户操作

### 组件关系
```
WorldClockPlugin (IPlugin实现)
    ├── WorldClockView (主界面)
    │   └── WorldClockViewModel (业务逻辑)
    │       ├── 时钟功能
    │       ├── 秒表功能
    │       └── 计时器功能
    └── SettingsView (设置界面)
        └── SettingsViewModel (设置逻辑)
```

### 数据流
```
用户操作 → XAML绑定 → ViewModel命令 → 业务逻辑
                                    ↓
                             属性更新 → 通知UI → 界面刷新
```

## 🚀 部署方式

### 自动部署（已完成）
```bash
# 构建插件
cd Plugins/WorldClockPlugin
dotnet build -c Release

# 复制到Plugins目录
Copy-Item bin\Release\net10.0\WorldClockPlugin.dll ..\..\Plugins\
```

### 手动安装
1. 将 WorldClockPlugin.dll 复制到 `Plugins` 目录
2. 重启应用程序
3. 插件会自动加载
