- 实时显示当前时间（每秒更新）

- 显示城市和国家信息

- 精确到毫秒（每10毫秒更新）

- 开始/停止/重置功能

- 显示选项配置

## 🔧 技术信息

### 基本信息

- **版本**: v1.0
- **DLL位置**: `Plugins/WorldClockPlugin.dll`
- **大小**: 51KB
- **依赖**: .NET 10.0, Avalonia 11.3.11

### 架构设计

- 采用 MVVM 模式
- 使用 `CommunityToolkit.Mvvm` 简化样板代码
- Timer 实现定时更新（时钟：1秒，秒表：10毫秒，计时器：1秒）
- ObservableCollection 管理时区列表

### 核心代码

```csharp
// WorldClockViewModel.cs
private void StartClock()
{
    _timer = new Timer(1000); // 每秒更新
    _timer.Elapsed += (s, e) => UpdateTime();
    _timer.Start();
}

private void UpdateTime()
{
    TimeZoneInfo timeZone = GetSelectedTimeZone();
    CurrentTime = TimeZoneInfo.ConvertTime(DateTime.UtcNow, timeZone);
}
```

## ❓ 常见问题

### 问题 1：插件未显示

**可能原因**: DLL 文件未正确放置  
**解决方法**: 
1. 检查 `Plugins/WorldClockPlugin.dll` 是否存在
2. 查看日志文件：`AvaloniaApplication2/bin/Debug/net10.0/Logs/`
3. 确认插件已启用

### 问题 2：时间不准确

**可能原因**: 系统时间和时区设置不正确  
**解决方法**: 
1. 检查系统时间是否正确
2. 检查系统时区设置
3. 重启应用

### 问题 3：秒表/计时器不工作

**可能原因**: Timer 未正确启动  
**解决方法**: 
1. 检查是否点击了"开始"按钮
2. 查看控制台是否有错误信息
3. 重新加载插件
