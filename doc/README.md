## 📖 文档规范

### 命名规范
- 格式: `编号-文档名称.md`
- 编号: DOC-XXX（技术文档）、DEV-XXX（开发文档）
- 使用中文命名，便于理解

### 内容格式
每个文档包含以下元数据：
```markdown
> **文档编号**: DOC-XXX  
> **版本**: vX.X  
> **创建日期**: YYYY-MM-DD  
> **最后更新**: YYYY-MM-DD  
> **贡献人**: [姓名/团队]
```

```
doc/
```

## 🔄 文档维护

### 更新流程
1. 修改对应文档内容
2. 更新"最后更新"日期
3. 如有重大变更，更新版本号
4. 更新本索引文件（如需要）

### 版本规范
- **主版本号** (X.0.0): 重大架构变更或功能重构
- **次版本号** (0.X.0): 新增功能或重要改进
- **修订号** (0.0.X): Bug 修复或小优化

### 贡献指南
- 保持文档风格一致
- 使用清晰的标题层级
- 添加代码示例时注明语言
